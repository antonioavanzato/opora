# ОПОРА · Заявки

Админка заявок с сайта [ОПОРЫ](https://oporasamitovva.ru) — бухгалтерия и управленческий учёт, Казань.
PWA: открывается в браузере и устанавливается на телефон как приложение.

**Открыть:** https://antonioavanzato.github.io/opora/

## Что умеет
- Вход по e-mail и паролю.
- Список заявок с квиза: поиск, фильтры по статусу, запросу и периоду; таблица на компьютере, карточки на телефоне.
- Карточка заявки: ответы квиза, рекомендуемый пакет (Лайт / Про / Премиум), «Позвонить» / «Написать в Telegram», статусы, заметки.
- Сводка: воронка, с чем приходят, сферы, форма бизнеса, размер команды.
- Выгрузка в CSV (Excel / Google Таблицы).
- Push-уведомления о новых заявках (Web Push).
- Удаление заявки (из админки и с сервера), обновление списка жестом «потянуть вниз».

## Вход
E-mail и пароль Арины. Пароль хранится в облаке только в виде хэша (scrypt), сессия — подписанный токен на 30 дней.

## Облако
Yandex Cloud (free tier): API Gateway → Cloud Function → YDB Serverless. Код и деплой — `cloud/` (`./deploy.sh function|gateway|all`). Адрес API — `js/config.js`; квиз лендинга шлёт заявки на `POST /leads`.

## Установка на телефон
- **iPhone (iOS 16.4+):** Safari → «Поделиться» → «На экран Домой». Push работает только у установленного приложения.
- **Android:** Chrome → меню → «Установить приложение».

## Безопасность
Репозиторий публичный: в нём **нет данных и секретов**. Заявки с персональными данными хранятся только в Yandex Cloud, доступ — по токену после входа.
